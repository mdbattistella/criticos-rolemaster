# Críticos Rolemaster

Módulo de Foundry VTT (v14, sistema dnd5e) con tablas de críticos y pifias al estilo Rolemaster.

## Instalación

En Foundry: **Add-on Modules → Install Module**, pegá este link en *Manifest URL* y tocá **Install**:

```
https://github.com/mdbattistella/criticos-rolemaster/releases/latest/download/module.json
```

Después activalo en tu mundo desde **Manage Modules**.
